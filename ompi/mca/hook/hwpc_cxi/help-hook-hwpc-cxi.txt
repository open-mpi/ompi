[no-cxi-device]
Cassini (CXI) hardware performance counter collection was requested, but
no Cassini device was found on this node. The job will now abort.

  Host:          %s
  Missing path:  %s

Either run the job only on nodes with a Cassini device, or disable counter
collection by setting the MCA parameter
hook_hwpc_cxi_counter_report to 0.
#
[mpi-t-needs-report-level]
hook_hwpc_cxi_counter_mpi_t_enable is set, but hook_hwpc_cxi_counter_report
is 0, so the hwpc_cxi component does not run and no Cassini counters are
registered as MPI_T performance variables.

To get the MPI_T performance variables, also set
hook_hwpc_cxi_counter_report to 1 (timeouts) or higher. Level 1 prints at
most a one-line network timeout summary.
